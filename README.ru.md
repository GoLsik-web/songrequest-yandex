# Заказ музыки для Twitch · Яндекс Музыка

**Зрители заказывают треки прямо со стрима, а музыка играет в твоей Яндекс Музыке.**

Зритель тратит баллы канала или присылает донат и пишет название трека.
Приложение находит трек и ставит его в очередь твоего приложения Яндекс Музыки
сразу за текущим. Когда заказы кончаются, твоя музыка продолжает играть с того
места, где остановилась. В кадре — аккуратная плашка «что сейчас играет».

## Для кого

Для стримеров на Twitch, которые слушают музыку в Яндекс Музыке и хотят, чтобы
зрители заказывали треки. Без ботов, сайтов и подписок.

## Что нужно

- Windows 10 или 11;
- **Яндекс Плюс** — без него Яндекс играет только отрывки по 30 секунд;
- приложение Яндекс Музыки на компьютере (или music.yandex.ru в браузере);
- канал на Twitch (для заказов за баллы — статус компаньона или партнёра);
- OBS, если нужна плашка в кадре.

## Как начать

1. Скачай архив со [страницы выпусков](../../releases/latest) и распакуй.
2. Запусти `songrequest-yandex.exe` — устанавливать ничего не надо.
3. Мастер настройки проведёт по шагам: вход в Яндекс, Twitch, награда за баллы,
   донаты и плашка для OBS. Любой шаг можно пропустить и вернуться к нему потом.

Дальше приложение тихо живёт в трее и обновляется одной кнопкой.

## Что умеет

- **Заказы за баллы канала или донат** (DonationAlerts, DonatePay, DonateX).
  Зритель пишет название или кидает ссылку на Яндекс Музыку, Spotify,
  YouTube, VK.
- **Честно с баллами.** Трек не нашёлся или не подходит под твои правила —
  баллы вернутся зрителю сами.
- **Твоя музыка не теряется.** После заказов Яндекс Музыка возвращается туда,
  где ты её оставил.
- **Плашка «что играет» для OBS** — много стилей и окрасок, ставится в любой
  угол кадра.
- **Нет в Яндексе — сыграет с YouTube**, если ты это разрешишь.
- **Команды в чате** для тебя и модераторов: очередь, пропуск, громкость,
  пауза, баны. Бот всегда отвечает, а не молчит.
- **Заказ целого плейлиста** отдельной наградой — играет после одобрения.

## Если что-то не работает

У каждой ошибки в панели есть короткий код (например, `YM-03`) и подсказка,
что делать. Подробнее — в инструкциях в папке [docs](docs). Кнопка «Сохранить
лог и историю» в настройках собирает всё нужное для разбора в один архив; данные
входа и ключи туда не попадают.

## Для разработчиков

```
go run .                      # своё окно с панелью внутри
go run . -в-браузере          # без окна, панель в браузере
go run . -без-браузера        # не открывать ни окна, ни браузера
go test ./...                 # тесты
.\build.ps1 -Version X.Y.Z    # dist\songrequest-yandex.exe и архив
```

Написано на Go. Панель — обычная веб-страница, вшитая в `.exe` вместе со
шрифтами, поэтому работает без интернета. Панель — `http://127.0.0.1:8978`,
виджет для OBS — `http://127.0.0.1:8978/widget`. Настройки, база и лог — в
`%APPDATA%\songrequest-yandex`. С версией для Spotify не пересекается: своя
папка, свой порт.

### Как устроена связь с Яндекс Музыкой

Официального API у Яндекс Музыки нет, поэтому приложение говорит с ней так же,
как её собственные клиенты (`internal/yandex`):

- **api.music.yandex.net** — поиск, треки, плейлисты, аккаунт. Токен берётся
  входом в окне приложения: после входа Яндекс кладёт его в адрес страницы,
  окно забирает его и закрывается. Токен лежит в хранилище паролей Windows.
- **Ynison** — постоянное соединение, через которое приложения Яндекса делят
  одну очередь воспроизведения. Приложение подключается к нему как пульт: видит,
  что играет у стримера, и вставляет заказ сразу за текущим треком.
- **Если Ynison недоступен**, заказ ложится в плейлист «Заказы со стрима», и
  баллы зрителя не пропадают.
- **Что играет прямо сейчас** приложение дополнительно читает из системной
  панели медиа Windows (`internal/smtc`, `internal/localapp`).

| Ссылка | Как берётся трек |
|---|---|
| Яндекс Музыка | напрямую по номеру трека |
| Spotify, Apple Music, Deezer | через song.link; не знает — поиск по названию |
| YouTube, VK | название и длительность через yt-dlp, потом поиск в Яндексе |
| Текст | поиск в Яндексе с подбором лучшего совпадения |

### Выпуск

`.\build.ps1 -Version 0.1.0` прогоняет тесты и кладёт `dist\songrequest-yandex.exe`
и архив. Выпуск — тег `v0.1.0` на GitHub с приложенным архивом: приложение
найдёт его по кнопке «Проверить обновления».

### Диагностика

Коды ошибок — в `internal/errs`. Подробный лог пишется всегда; «Сохранить лог и
историю» собирает в `.zip` лог, историю заказов, настройки и сведения о
системе, ключи вырезаются.
