# Заказ музыки для Twitch · Яндекс Музыка

Локальное приложение: зрители заказывают треки за баллы канала или донат, а
музыка играет в Яндекс Музыке самого стримера. Заказ встаёт в очередь его
приложения Яндекс Музыки сразу за текущим треком; когда заказы кончаются,
музыка возвращается туда, где стример её оставил.

Один `.exe` без установки: скачал, запустил, дальше приложение проводит по
настройке само — вход в Яндекс, Twitch, награда за баллы, виджет для OBS.
Обновляется по кнопке в панели, выпуски берутся отсюда, со страницы
[выпусков](../../releases).

## Как это устроено

Официального API у Яндекс Музыки нет, поэтому приложение говорит с ней так же,
как её собственные клиенты (`internal/yandex`):

- **api.music.yandex.net** — поиск, треки, плейлисты, аккаунт. Токен берётся
  входом в окне приложения: после входа Яндекс кладёт его в адрес страницы,
  окно забирает его и закрывается. Токен лежит в хранилище паролей Windows.
- **Ynison** — постоянное соединение, через которое приложения Яндекса делят
  одну очередь воспроизведения. Приложение подключается к нему как пульт,
  который сам ничего не играет: видит, что играет у стримера, и вставляет
  заказ в очередь сразу за текущим треком.
- **Если Ynison недоступен**, заказ ложится в плейлист «Заказы со стрима», и
  баллы зрителя не пропадают.
- **Что играет прямо сейчас** приложение дополнительно читает из системной
  панели управления медиа Windows (`internal/smtc`, `internal/localapp`) —
  бесплатно и без сети.

Ссылки, которые кидают зрители:

| Ссылка | Как берётся трек |
|---|---|
| Яндекс Музыка | напрямую по номеру трека |
| Spotify, Apple Music, Deezer | через song.link: чаще всего он знает тот же трек в Яндексе; не знает — поиск по названию |
| YouTube, VK | название и длительность через yt-dlp, потом поиск в Яндексе; не нашлось — по выбору стримера играет с YouTube |
| Текст | поиск в Яндексе с подбором лучшего совпадения |

## Запуск для разработки

```
go run .                      # своё окно с панелью внутри
go run . -в-браузере          # без окна, панель в браузере
go run . -без-браузера        # не открывать ни окна, ни браузера
go test ./...                 # тесты
```

Панель живёт на `http://127.0.0.1:8978`, виджет для OBS —
`http://127.0.0.1:8978/widget`. Настройки, база и лог — в
`%APPDATA%\songrequest-yandex`. Со старым приложением для Spotify не
пересекается: своя папка, свой порт.

## Сборка релиза

```powershell
.\build.ps1 -Version 0.1.0
```

Прогоняет тесты, кладёт `dist\songrequest-yandex.exe` и архив с запиской.
Выпуск — тег `v0.1.0` на GitHub с приложенным `.exe`: приложение у стримеров
найдёт его по кнопке «Проверить обновления».

## Оформление

Тема «Нефор» (`internal/server/web/theme.css`): тёмная ксерокопия, толстые
рамки, жёсткие тени без размытия, заголовки рубленым капсом (Dela Gothic One),
служебное — моноширинным (JetBrains Mono), текст — Onest. Одна краска —
жёлтый. Шрифты вшиты в программу: панель работает без интернета. Виджет для
OBS по умолчанию в том же оформлении.

## Диагностика

- Каждая ошибка показана с коротким кодом (`YM-08`), который можно
  продиктовать голосом. Коды Яндекса — в `internal/errs`.
- Подробный лог пишется всегда.
- «Сохранить лог и историю» собирает в один `.zip` лог, историю заказов,
  настройки и сведения о системе; ключи доступа вырезаются.
